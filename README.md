# Togo_AI_Lab_Technical_Assessment
This repos contains the technical assessment of Togo AI Lab directed by CEGA. This assessment has be performed by Komi NAGBE

The assessment tasks have been done in file cega_test_responses_komi_nagbe.ipynb. At the top of this file, be sure to set the appropriate working directory before to run the rest of the code. Some packages are needed to be installed before start executing the rest of the code
